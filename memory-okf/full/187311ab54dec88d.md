## KEY REFINEMENT (shrinks blast radius ~3x)
Only the FLOP-bearing ops go canvas-only; the cheap per-row kernels (attn_norm, q/k/v_norm, gelu,
k_add, post_*_norm, region_scale) STAY FULL-WIDTH. They are per-row independent: canvas rows get
correct inputs (canvas-only GEMM outputs), prompt rows hold garbage that is NEVER read (prompt
queries not computed; Kst prompt rows come from cache). So no offset bug is possible in the ~20
per-row launches; only the GEMMs + attn + MoE-router-loop need offsetting.
