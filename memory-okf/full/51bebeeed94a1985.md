# FAITHFUL-F1b.1: recall-path faithfulness ATTRIBUTED (pure-KV replay = 0% obey)

**Banked 2026-07-01. Engine main `62fcfb0`. Harnesses `tests/perf/_g_faithful_recall.py` + `tools/xbar_lsh/_seed_faithful.py`; receipts `tests/fixtures/faithful/G-FAITHFUL-RECALL-WC{.log,.json,-trace.log}`.**

## Result (served gemma4-12b-b1, same 15 fact-conflicts as F1, delivered via recall not prompt)
- **In-context text (F1 ceiling): 100% obey.**
- **Pure-KV replay recall (SP_B3_WC → kv::replay@M_target=42): OBEY 0/15.**
- Daemon trace (now observable via the new SP_DAEMON_LOG): **W_c FIRED + replayed on 14/15** turns (only 1 NULL). So this is NOT a threshold/selector-NULL tuning miss.

## Attribution (the whole point of the diagnostic)
Two compounding failures in the pure-KV recall path, both real:
1. **Delivery**: even when the correct-ish episode is replayed, the attenuated pure-KV injection (M_target=42) does NOT override a strong parametric prior → the model answers parametrically. (M_target=42 is deliberately attenuated so recall BINDS instead of HIJACKS synthesis — fine for novel needles with no competing prior, fails against strong priors.)
2. **Selection quality**: the W_c head was trained on HIGH-ENTROPY novel needles ("8-FALCON-7729"); on natural-language facts (mutually similar) it mis-discriminates — the trace shows it repeatedly picking the same wrong episode (fct_014/speed_light) for unrelated questions.

## The fix (architectural, receipts-backed) — F2
**Route recalled FACTS through text-in-context delivery, NOT pure-KV replay.** F1 already proved the model obeys an in-context fact 100%. So the recall path should, on a confident match, prepend the episode TEXT to the prompt (the B3-JUDGE/augmented-prompt synthesis seam) rather than replay its K/V. Pure-KV replay stays valid for novel-needle recall (no competing prior) but is the wrong delivery for fact-conflict / prior-override.
- Open: an earlier SP_B3_JUDGE (text-synthesis) run also leaked, but that was likely selection-NULL (the judge/selector didn't engage), NOT delivery — needs a clean re-run with the selector confirmed firing (now possible with SP_DAEMON_LOG). The clean F2 test: force the CORRECT episode's TEXT into context (RAG) on a recall hit and confirm ~100%, then wire that as the recall delivery.
