# Ring-3 Path B (the n->k gist compression) under ADR-002 is a GIST HEAD on the decide spine, NOT a standalone adapter model. DO NOT build Path B as a separate model. Consolidation = a DECIDE op (select spans / compress n->k / emit content-address key) -> ADR-002 makes deciders cheap heads on the resident EAGLE/MTP draft body, never models. So Path B collapses to a gist head in the W_c/Memory-Head family on the global-K/L5 retrieval substrate (fact signal proven there: L5-cosine 86.89%; draft-body->global-K bridge = fallback entry). Must be RECOGNITION/shortlist (emit key; Ring-2 exact bytes carry fidelity via retrieve-and-verify), NOT reconstructive -- forced by P2.b (span->k generation dead; recognition top-5 0.77) AND the never-fuse rule. Still DEFERRED-by-evidence: only if Path A's parameter-free shortlist is MEASURED insufficient (the 16x-32x budget-ladder MISS). When due = a head + distillation gate on the existing spine, not a model/training campaign. Path A (VSA/HRR) is already CLOSED (G-R3-NIGHTSHIFT a64a916).

Recorded as graduation #4 (Consolidation) in PPT-LAT-ADR-LATENT-NATIVE-UNIFICATION.md + amendment in CONTRACT-XBAR-R3-consolidation.md. Substrate rule: retrieval/gist rides global K/Q (read_global_q/read_global_k), not the capture_feat classifier tap. The ep.l5 mint (branch feat/nightshift-l5-live) is a step toward this: live episodes carry the L5 key the head reads.
