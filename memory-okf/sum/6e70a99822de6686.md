# Telemetry flywheel END-TO-END: harness sinks /v1/events into durable content-addressed store (G-HARNESS-TELEMETRY-SSE)

Harness half of LM-B2 SSE sink GREEN (harness 7a131c3). SPDaemonClient.subscribe_events(want=['telemetry']) = long-lived GET /v1/events consumer (extends the lifted CosySim client). harness/telemetry/sink.py TelemetrySink = content-addressed idempotent durable store: records/<sha16>.json + log.jsonl index, dedup by content hash, writes record VERBATIM (already engine-redacted, never un-redacts), stdlib only, .run(client,stop) loop for a daemon thread. Distinct from Nexus KB + memory-okf/ episodes = the raw telemetry corpus tier. GATE G-HARNESS-TELEMETRY-SSE: live daemon + 2 queries -> 4 records sinked (2 decision + 2 turn), REDACTION PASS (secret 0 hits in every file), dedup idempotent. FLYWHEEL NOW END-TO-END: engine decision+turn telemetry -> /v1/events -> harness subscribe -> durable content-addressed corpus that accumulates across sessions, privacy preserved on the wire AND at rest. DO NOT rebuild. RECON FINDING: the harness runtime IS lifted from cosysim (do NOT rebuild, extend); the router-finetune-on-telemetry pipeline is in EXTERNAL cosysim/nexus proper (needs operator access). FOLLOW-ON: wire TelemetrySink.run into run_agency.py/agency.py as an idle-safe background thread (auto-collect); memory-okf LUT row; then the data-gen/finetuning phase (recon external cosysim/nexus FIRST).
