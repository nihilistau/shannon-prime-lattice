# SP-SWARM L1+L2 replication core GREEN (transport-agnostic): have/want convergence + verify-on-arrival + tamper-reject over real MEM-OKF; two address classes

First SP-SWARM brick built+gated (tools/swarm_sync.py + g_swarm_converge.py). G-SWARM-REPLICATE-CONVERGE GREEN over the real 113-object MEM-OKF store: content-address round-trip, bidirectional have/want -> both nodes reach the byte-identical union (113/113), verify-on-arrival, idempotent (re-sync 0), tamper-reject (corrupted content object rejected integrity-fail). GROUNDED FINDING: MEM-OKF has TWO address classes - content-addressed (agent facts, sha256(norm(body))[:16], tamper-evident by re-hash) + C2-addressed episodes (256-bit C2 SimHash via --addr, NOT body-re-hashable, integrity=self-consistency now + Ed25519 at L3). Store split 87 content / 26 c2. Transport-agnostic: manifest/have/want/pull/sync seam; libp2p L0 (noise/X25519/Ed25519 roster) layers UNDER the seam later without touching reconciliation. NEXT: L3 Ed25519 provenance -> L0 libp2p -> Rust port. Anti-rebuild: replication logic DONE; don't rebuild. Receipt tests/fixtures/swarm/G-SWARM-REPLICATE-CONVERGE.log.
