# Telemetry flywheel GREEN: every recall decision logged, class-redacted (G-LM-TELEMETRY, LM-B2)

ADR-005 LM-B2 GREEN (engine decision-telemetry core). routes.rs telem_emit_recall logs a structured JSONL record at all 3 terminal recall branches (decline/margin-skip/deliver): query/entry/class/cos/margin/delivery/decision. Private-secret queries REDACTED to a hash (privacy-before-data). Gated SP_TELEMETRY=1 + SP_TELEMETRY_LOG, off token path, default-off null floor. GATE: mixed corpus -> 6 records (private-secret 4, counterfact 1 systemecho, persona 1 system), cos[deliver] 0.985 vs cos[decline] 0.932, REDACTION PASS (secret 0 hits in log). This IS the data to tune tau/margins, build a finetune set, detect drift. DO NOT rebuild. Follow-on: per-turn timings + OUTPUT-join (engine emits telemetry SSE event on events_tx, harness StreamProcessor sinks with output+obey/leak) + PoUW SpinorReceipt per record. Next: LM-B3 adaptive classify. telemetry_report.py = the view.
