# PowerShell [IO.File] uses process CWD not Set-Location - use ABSOLUTE paths

PowerShell cd does NOT change .NET process CWD; [IO.File]::ReadAllText/WriteAllText with relative paths hit C:\Users\Knack and silently fail. Always use absolute paths for .NET IO.
