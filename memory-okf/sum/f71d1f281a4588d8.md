# N5c MoE flip = 4.6x per-forward collapse (80.6s -> 17.5s f32->packed dp4a), rc=0 parity

MEASURED (test_dg_forward_timing warm, engine 16cfff2): diffusion forward 80.58s (all f32) -> 17.47s (dense-MLP + 128-expert MoE all packed dp4a via dg_gemm_packed_rows) = 4.6x / -78%, rc=0 (int8 act-quant ~1e-3 parity, same as dense decode). The MoE was the bulk of the 26B = the wall. Packed OK_Q4B across PCIe (half the f32 H2D) + dp4a unpack on-device; no new kernel, gated SP_DG_PACKED (default-off=f32 null floor). Still f32: Wq/Wk/Wv/Wo + head (more on the table). 48-step query ~64min -> ~14min. Prior: dense-only flip was -5.6% (b23c0f0); N5b host-reservoir was DEAD overhead (82s>78s). NEXT: flip attention+head, map sp_forward_dispatch_fn + Rust ABI streaming, VRAM hot-expert LRU, purge N5b.
