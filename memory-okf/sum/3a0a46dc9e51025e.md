# LN-1 HYBRID negative (root-caused): global-K/Q last-token Q is content-poor; semantic channel DEAD; use pooled embedding

Hybrid alpha*SEM(raw q.K on global-K/Q) + beta*LEX(token-overlap), 61 facts x exact+anti-lexical-para, dual-axis held-out. SEM-only=0% on BOTH exact+para (below chance); optimizer fitted alpha=0 -> hybrid==pure Jaccard (exact 1.000, para 0.067). ROOT CAUSE: read_global_q captures the LAST-token global-Q which is query-content-POOR (queries end similarly) -> query-INDEPENDENT ranking; that's why W_c (16.7%) AND raw q.K (0%) both fail. The global-K/Q substrate carries the recall MECHANISM, not a query embedding. DO NOT build a latent semantic recall channel from last-token global-K/Q. The proven semantic-retrieval latent is a POOLED sentence embedding (TELE-1 mean-pooled, retrieval@1 1.000) -- a DIFFERENT capture (mean over query content tokens / dedicated embedding). Jaccard stays the exact selector (100%); paraphrase recall needs a pooled-embedding dense retriever if pursued. Engine 024d0dd; receipt tests/fixtures/faithful/G-LN-1-HYBRID-DUALAXIS.log.
