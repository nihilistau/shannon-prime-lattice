# SP-SWARM integrated into sp-daemon GREEN (default-off swarm feature): run_node orchestration + sp-swarm-node bin + daemon spawn hook

Integration phase. (1) sp_swarm::transport::run_node (serve+periodic pull+persistent identity+roster file) — G-SWARM-NODE GREEN: 2-node autonomous sync converge 5/5 both ways, identity stable, roster parsed. (2) sp-swarm-node bin (headless replication node, no 12B). (3) sp-daemon wiring: optional dep sp-swarm{transport} + feature swarm; lib.rs pub mod swarm (cfg); daemon.rs run_inner calls sp_daemon::swarm::spawn_if_enabled() before HTTP server; SP_SWARM=1 spawns run_node on SP_SWARM_PORT (own port, NOT the garner --quic-port) with a PERSISTENT SP_SWARM_KEY identity (daemon node key is ephemeral) + SP_SWARM_ROSTER, replicating SP_OKF_ROOT. G-SWARM-DAEMON-WIRE: cargo build --features wire_cuda_backend,swarm builds+links (19.33s). Default-off = null floor. GOTCHA: daemon.rs is a BIN module (main.rs mod daemon) so the hook is sp_daemon::swarm:: (not crate::). Remaining: multi-host beyond loopback; peer discovery only past invite-list; L4 C2 overlay. Anti-rebuild: integration DONE; don't rebuild. Receipts G-SWARM-NODE.log, G-SWARM-DAEMON-WIRE.log.
